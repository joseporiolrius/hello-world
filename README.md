# hello-world — Session 1

Your first DBAI24 repository. This session takes place **in the browser**:
no terminal, local installation or AWS account is needed.

## Create your private copy

1. Open [the ESADE course template](https://github.com/joseporiolrius/hello-world).
2. Choose **Use this template → Create a new repository**.
3. Select your own account, name the repository **hello-world**, and choose **Private**.
4. Add **joseporiolrius** in **Settings → Collaborators → Add people**.
5. Open **Actions → hello**, open the run and read the log. Find the output
   from `hello.py`: `hello, world`.

Keep the repository private. Submit its URL through the eCampus form.

## Lab — edit, commit, verify, journal

1. On your repository page, press **.** to open github.dev.
2. Fill in `ABOUT.md`: name, degree track, and one system you use daily
   that you could not operate yourself.
3. Commit and push with `docs: add student profile`.
4. Return to **Actions**. Check that the new `hello` run is green and read its log.
5. Ask an AI assistant to explain `.github/workflows/hello.yml`, including its
   triggers. Verify its claims against the workflow file and the run's details.
6. Acknowledge the AI-use contract in `JOURNAL.md` with your name and **S01**.
   Write your first entry using **Asked / Wrong / Changed / Verified**, then commit
   with `docs: acknowledge AI contract and add journal entry S01`.
7. Upload a green-run screenshot as `evidence/s01-actions-green.png` through
   GitHub's **Add file → Upload files**. Use `docs: add S01 evidence screenshot`.

You should have at least **three commits of your own**, a personalized profile,
a specific journal entry, the screenshot, and a green latest Actions run.
